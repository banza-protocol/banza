more than qualifying.

## Agreements

- [ ] We will implement only from the frozen package and the resources listed as permitted in
      `ISOLATION_AND_PROHIBITED_SOURCES.md`.
- [ ] We will not consult the BANZA reference implementation, engines, Operator Zero source, private
      branches, internal audits or BanzAI as a normative source.
- [ ] We will not search for BANZA source mirrors, engine snippets or cached implementation material.
- [ ] We will record every question in the ledger **before** it is answered, in our own words, and will
      not edit questions afterwards.
- [ ] We will report accidental exposure to a prohibited source rather than conceal it, understanding
      that the technical result remains useful and only the independence claim is affected.
- [ ] We understand the implementation is frozen at our declaration of completeness, before any
      comparison with the reference implementation.
- [ ] We understand that a result of `FAIL` or `SPECIFICATION_BLOCKED` is a legitimate outcome and is
      not a judgement of the team.
