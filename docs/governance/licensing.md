# Licensing

This document records how the BANZA repository is licensed. It is descriptive; the
authoritative texts are the `LICENSE` and `NOTICE` files at the repository root.

## Code, contracts and specifications — Apache License 2.0

The source code, protocol contracts and specifications in this repository are licensed
under the **Apache License, Version 2.0**. The full, unmodified license text is in
[`LICENSE`](../../LICENSE); the copyright/attribution notice is in
[`NOTICE`](../../NOTICE).

The root `LICENSE` contains the **standard, unmodified Apache-2.0 terms** (so it is recognised
by automated tooling such as GitHub's license detection). Its "APPENDIX: How to apply the
Apache License to your work" boilerplate copyright line is completed with the actual owner —
`Copyright 2026 BANZAMI - TECNOLOGIA E SERVIÇOS, LDA.` — exactly as that appendix instructs;
this fills a template placeholder and does not alter any license term (license detection
strips copyright lines and is unaffected). Fuller project attribution also lives in `NOTICE`.

## Documentation — Creative Commons CC BY 4.0 (as stated in the README)

The project `README` states that public **documentation** is published under
**Creative Commons Attribution 4.0 International (CC BY 4.0)**. This document records that
stated policy; it does not extend or change it. Formalising the documentation license
(for example, per-file markers or a dedicated documentation license file) is a governance
follow-up and will be confirmed through the normal governance process. Where a specific
document carries its own license marker, that marker governs that document.

## Summary

| Artifact | License | Where |
|---|---|---|

| Copyright / attribution notice | — | [`NOTICE`](../../NOTICE) |

Nothing in this document is legal advice. In case of any conflict, the `LICENSE` and
`NOTICE` files and any per-file license markers govern.
