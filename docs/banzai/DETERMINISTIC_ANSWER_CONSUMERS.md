# BanzAI deterministic-answer consumer inventory

Every place that reads a KNOWLEDGE ENTRY's `answer`. Generated by measurement, not by memory.

This file exists because a locale migration was attempted and reverted. The locale architecture was
sound and the product code was nearly unaffected — but `entry.answer` turned out to be read almost
entirely by TESTS AND GUARDS, and removing it took the verification layer red faster than it could be
repaired. The ratio below is the whole lesson: the migration surface is not the product.

Excluded deliberately: the API RESPONSE payload's `answer` property, which is a different field with a
different owner and is not affected by entry-schema changes.
