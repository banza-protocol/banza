# BANZA Trademark Policy

This policy separates the **open-source license** (Apache License 2.0) from the use of the project's
**names, logos and visual identity**. The open-source license lets you use the covered code and
documentation; it does **not** automatically grant rights to use the marks.

Nothing here is legal advice. In case of conflict, `LICENSE`, `NOTICE` and applicable law govern.

## 1. Covered marks

- **BANZA**, **BanzAI**, **Banzami**
- Their logos, symbols and visual identity (trade dress)
- Associated product/protocol names and official domains

## 2. Main rule

The open-source license (Apache-2.0) permits use of the code and documentation it covers.
**The open-source license does not grant any right to use the BANZA, BanzAI or Banzami marks.**

## 3. Permitted use without special authorisation

- Nominative reference to the protocol and the project
- Attribution (e.g. crediting the origin as required by `NOTICE`)
- A fork that clearly states it is a fork
- Documentation that cites the protocol
- Integration statements such as "compatible with the BANZA protocol", provided they do **not** suggest
  approval, certification or partnership
- Contributions in the public repository
- Textual use to explain origin and compatibility

## 4. Use that needs care or separate authorisation

Avoid, or obtain separate written permission for:

- Using a BANZA/BanzAI/Banzami logo as the primary mark of your own product
- Suggesting an official partnership
- Suggesting an approved or certified operator
- Suggesting a Banzami endorsement
- Claiming an implementation is "official BANZA" without acceptance through the public repository process
- Registering confusingly similar domains
- Using the visual identity in a misleading way

## 5. Allowed phrases

- `Implements the BANZA protocol.`
- `Compatible with the BANZA protocol.`
- `Built using the open BANZA protocol.`
- `Fork of the BANZA protocol repository.`
- `Independent implementation of the BANZA protocol.`

## 6. Phrases that are prohibited or require authorisation

- `Certified BANZA operator.`
- `Approved by BANZA.`
- `Licensed by BANZA.`
- `Official BANZA operator.`
- `BANZA-certified.`
- `Banzami-approved operator.`
- `BANZA CA certified.`

These imply central approval or certification, which the protocol does not perform.

## 7. Relationship with Banzami

Banzami is the original creator and initial institutional maintainer of the BANZA protocol. This
attribution does not make every independent implementation a Banzami product or service.

## 8. Relationship with open governance

Protocol governance happens through public repository processes. Trademark use does not replace protocol
governance, technical evidence or peer verification. Participating in governance or contributing does not
automatically grant trademark rights.
